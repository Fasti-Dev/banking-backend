# User Stories

## Customer

- Als Nutzer möchte ich einen Kunden anlegen.
- Als Nutzer möchte ich Kundendaten anzeigen.

## Account

- Als Nutzer möchte ich ein Konto für einen Kunden erstellen.
- Als Nutzer möchte ich den Kontostand ansehen.

## Money Movement

- Als Nutzer möchte ich Geld einzahlen.
- Als Nutzer möchte ich Geld abheben.
- Als Nutzer möchte ich Geld überweisen.

## Transaction

- Als Nutzer möchte ich alle Transaktionen eines Kontos sehen.
